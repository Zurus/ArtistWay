### STAGE1

# Роль
Ты — Senior Android Developer и Game Designer с опытом в казуальных играх 
и работе с внешними API (особенно TMDB).

# Контекст проекта
Мы проектируем Android-игру «КиноСвязи» (рабочее название). 
Суть: игроку даётся пара (Стартовый актёр, Целевой актёр). 
Задача — построить цепочку:
  Актёр → Фильм (где оба снимались) → Актёр → Фильм → ... → Целевой актёр.
Пары генерируются динамически. Источник данных — TMDB API.

# Задача ЭТАПА 1 (единственная, не выходи за её рамки)
Создай файл `docs/01_concept.md` — Game Design Document lite. 
Включи следующие секции:

1. **Core Loop** — пошаговое описание одного игрового цикла.
2. **Экраны приложения** — список экранов с кратким описанием 
   (что видит игрок, какие действия доступны).
3. **UX-флоу** — путь пользователя от запуска до окончания партии.
4. **Правила генерации пары** — высокоуровневые требования к паре 
   (связность, длина пути, сложность). Детали алгоритма — на этапе 4.
5. **Ограничения TMDB API** — что мы знаем о лимитах, 
   какие эндпоинты точно понадобятся (без детализации контрактов).
6. **Edge cases** — минимум 5 сценариев, которые могут сломать игру 
   (нет пути, API недоступен, зацикливание и т.п.).
